RECORDING TIPS
- 1080p screen capture, browser zoom 100-110%.
- No API keys on screen at any point (keys stay server-side).
- Keep the server terminal out of frame, or show one clean start.
- Do one rehearsal run first so uploads and numbers are familiar.
- Export/unlist on YouTube or Loom and paste the link in the entry.
